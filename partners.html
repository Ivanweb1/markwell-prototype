Стать частью MarkWell

Работаем с профессиональной средой

Мы развиваем форматы сотрудничества для частных мастеров, салонов, студий и школ, которые работают с мастерами каждый день.

01 / Кому подходим

Три формата сотрудничества

Условия различаются по роли и масштабу проекта. Точные экономические параметры будут опубликованы только после расчёта и согласования модели.

Частный мастер

Реферальный формат для мастеров, которые используют MarkWell и готовы рекомендовать оборудование профессиональной аудитории.

Салон / студия

Для бизнеса, который ценит эстетику и эргономику рабочего пространства и оснащает одно или несколько рабочих мест.

Школа

Для образовательных проектов, которые знакомят будущих мастеров с профессиональным оборудованием.

02 / Что даём

Возможности для каждого формата

Ниже перечислена структура программы из ТЗ. Финальные коммерческие условия ожидают согласования.

Частный мастер

  • Персональный код / реферальная ссылка
  • Вознаграждение за подтверждённые продажи
  • Статистика
  • Специальные условия на расходники

Салон / студия

  • Специальные условия на оснащение
  • Ступенчатая модель в зависимости от объёма
  • Помощь с подбором оборудования
  • Условия на повторные закупки

Школа

  • Специальные условия на учебные места
  • Партнёрский код для учеников
  • Обучающие материалы
  • Возможные бонусы за подтверждённые покупки / регистрации
